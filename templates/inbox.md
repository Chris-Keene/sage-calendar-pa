# Sage inbox

Jot anything here that isn't in an email, Slack or Jira yet and Sage will find it a slot.
One task per line, written like `- [ ] Draft the Q4 enablement plan ~60m !2 due:2026-10-16`.
Optional tags: `~45m` (estimate, default 30), `!1` / `!2` / `!3` (priority, default 2), `due:YYYY-MM-DD`.
Tick it `[x]` or delete the line when it's done.
